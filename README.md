# 🥕 Bouffe

**👉 https://9wsv9ngdft-cmd.github.io/bouffe/**

Une web app toute simple pour gérer le frigo, le congélateur, les placards, les dîners et les courses.

Sur iPhone : ouvrir le lien dans Safari → bouton Partager → « Sur l'écran d'accueil ».

## Ce qu'elle fait

- **Scan des codes-barres en continu** : un bip par produit. Le nom, la catégorie, le Nutri-Score et la mention végé/vegan viennent d'Open Food Facts.
- **Boutons rapides** pour le frais et le vrac, qui n'ont pas de code-barres.
- **Dates estimées** selon le type de produit, corrigeables en un geste. La date raccourcit quand on marque un produit « ouvert ».
- **À manger en priorité** : ce qui périme bientôt, avec les boutons fini / jeté / congeler.
- **14 dîners planifiés** à partir du stock, en commençant par ce qui périme. Base végé, avec la viande ou le poisson proposés à côté.
- **Deux listes de courses** : « frais » pour l'appoint des prochains jours, « livraison » pour la quinzaine. Les produits de base s'y ajoutent dès qu'ils manquent.

## Vie privée

Tout est enregistré uniquement sur le téléphone. Seul le numéro du code-barres est envoyé à Open Food Facts. Il n'y a ni compte ni serveur.
